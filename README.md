# 电竞经理 2026 数据库编辑器

《电竞经理 2026》（Esports Manager 2026）的中文可视化数据库编辑器。支持游戏原生 EMDB、配套图片、两库合并与 EMSkin 模组赛历。

## 下载与启动

打开 [Releases](https://github.com/miku88888/EsportsManager2026Editor/releases/latest)，下载 **EsportsManager2026Editor-v1.3.1-windows-x64.zip**。这个 ZIP 自带 Node.js，Windows 10 / 11 64 位解压后即可使用。

1. 完整解压到一个有写入权限的文件夹。
2. 双击 **启动编辑器.cmd**。
3. 首次启动时选择游戏安装文件夹（包含 `EsportsManager_Data`）及 `.emdb` 数据库。向导会尝试发现 Steam 的 World Updated 订阅。
4. 图片可选整个 `ImagesPack` 或 `BepInEx/emskin` 文件夹。也可以先留空，进入编辑器后再导入。
5. 如需导出完整 BepInEx 整合包，选择已解压的原模组目录；皮肤目录可选，用于叠加图片与素材。选择模组自带 `emskin/database` 中的 EMDB 时会自动识别模组目录。
6. 点击“保存配置并启动”，在浏览器中开始编辑。退出服务请双击 **停止编辑器.vbs**。

运行服务只监听本机 `127.0.0.1`。程序建立独立工作副本，原数据库和图片不因日常编辑而改变。数据库用于新建生涯；已有生涯不会自动随外部数据库更新。

## 导入数据库与图片

左侧选择 **数据库与图片**，依次选择 `.emdb`、配套图片文件夹或图片 ZIP，点击 **导入为新副本并切换**。副本会保留，可随时切回。

支持整体选择图片根目录，无需逐个分类导入：

| 图片包分类 | EMSkin 分类 | 内容 |
| --- | --- | --- |
| Players | photos | 选手 |
| Staffs | staff | 职员 |
| Teams | teamlogos | 战队 |
| Tournaments | logos | 原生赛事模板 |
| Sponsors | — | 赞助商 |

已有副本可选择 **合并图片：同名更新，其余保留**。添加少数选手或战队请使用 **追加数据（新增 / 更新）**，相同 ID 更新，其余记录保留。单张图片支持 PNG / JPEG / WebP，最多 12 MB；图片 ZIP 最多 512 MB、解压后最多 700 MB / 50,000 项，大包请解压后选择文件夹。

## 编辑与合并

- 双击选手、职员、战队、赞助商或赛事模板打开完整资料；设置中保留侧边面板模式。
- 新增、复制、删除与批量修改；关联改名和转会同步阵容引用。修改已有头像后立即保存并刷新，自动按记录 ID 绑定。
- 图片支持已确认的真实名 / 游戏替代名映射；“图片资源”可修复 ID 绑定。设置中选择同 ID 图片优先来源，手动选图仍优先。缺少原图的记录需要自行补图。
- **两库合并 / 冲突**：先建立独立合并副本，再逐项比较 A、B 和手动结果；可指定图片优先 A 或 B。
- 支持批量随机 A / B、数值字段取最小值、保留 A / B / 当前。批量范围可选待处理或全部；数值取小不处理文字和空值。重复 ID 会保留记录并生成身份核对项。
- 数据库修改支持撤销 / 重做。图片操作和数据库撤销分开；合并审核进度保存在工作副本中。

## 模组赛历

EMDB 的赛事表是原生赛事模板。EMSkin 中每年的实际赛事安排存放在独立的 `calendar` CSV 文件中，两者数量不同。

在 **模组赛历** 中选择赛历文件夹，或点击连接已配置模组的赛历。支持 `calendar_t1…t4.csv`、年份赛历、`pool.csv`、`majors.csv` 和 `cities/*.csv`。可编辑、增加、删除配置，保留原文件、注释与独立撤销历史。动态赛事池表示生成来源，不等于每年实际赛事总数。

## 导出给游戏

- **导出 .emdb**：在游戏主菜单的数据库页面导入，用此数据库新建生涯。
- **导出数据库 + 图片**：生成 `DatabasePack` 与 `ImagesPack`；图片可通过游戏本地图片包功能使用。
- **导出完整整合包 ZIP**：配置原模组后可用。保留原插件及素材，覆盖当前数据库、图片选择与已导入的赛历，生成同结构 `BepInEx` 文件夹。备份原模组后将整个文件夹复制到已安装该模组的游戏目录，合并覆盖。

完整模组 ZIP 来自用户本机提供的原模组和皮肤。这个项目和下载包只提供编辑器；数据库、人物头像、游戏文件和第三方模组需自行准备。

## 本地文件与升级

- `settings.json`：首次启动生成的本机配置。
- `project/`：工作副本、图片、合并进度、原始备份与缓存。
- `exports/`：导出文件。

升级前备份以上三项。解压新版程序后把它们复制到新版目录，修改 `settings.json` 的 `projectDir` 指向迁移后的 `project`。本机游戏和素材目录保持有效即可。不要将这些个人文件提交到公开仓库。

目前支持 EMDB v2 / v3，读取本机游戏 metadata v107 中的格式信息；未捆绑游戏密钥。游戏更新改变格式时可能需要适配。完整 BepInEx ZIP 当前按 iamgri / EMSkin 目录约定生成。

## 源码运行与验证

安装 Node.js 22 或更新版本，无第三方 npm 依赖。Windows 可直接运行 `启动编辑器.cmd`；向导会使用系统 Node.js。其他启动方式：

```sh
npm test
node server.mjs
```

直接启动服务前，请先按 `settings.example.json` 创建 `settings.json`，或通过 Windows 首次配置向导生成。测试使用合成数据，不要求安装游戏，不读取个人存档。

`npm run build` 会按明确文件清单生成源码 ZIP；如 `runtime/node.exe` 和 `runtime/LICENSE.txt` 存在，还会生成 Windows 便携 ZIP，并输出 SHA-256 校验值。运行数据、图片和模组不会进入发布包。

编辑器代码使用 MIT 许可。Node.js 及其组件许可见便携包 `runtime/LICENSE.txt` 和 `THIRD_PARTY_NOTICES.md`。本项目为社区工具。
